# Hisar Mobile

iOS and Android apps on top of the gomobile-bound `core`. Phase 4 — see [docs/DESIGN.md](../docs/DESIGN.md#93-mobile--gomobile--native-ui).

- `hisarkit/`: the Go backend, built into `build/HisarKit.xcframework` with `make build-ios-framework`.
- `ios/`: the iOS app and AutoFill extension; see [ios/README.md](ios/README.md).
