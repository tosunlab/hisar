# Hisar Desktop

Wails v3 (pinned beta, see `WAILS_VERSION` in the root `Makefile`) with a Vue 3 + TypeScript frontend.

| Path | What |
|---|---|
| `vault/` | Go backend bound to the UI: session, lock/auto-lock, clipboard clearing. No Wails import, so it is tested on any OS |
| `main.go` | Wails app: window, clipboard and lock-event adapters |
| `frontend/src` | UI: `api.ts` (only file that calls the bindings), `store.ts` (state and actions), `components/` |
| `frontend/bindings` | Generated by `wails3 generate bindings` during every build; committed, and CI fails if a build changes them |
| `build/` | Platform build config (macOS, Linux) |

## Build and run on macOS

Requires Go 1.26+, Node 24 and Xcode command line tools.

```sh
make install-wails          # installs the pinned wails3 CLI into ~/go/bin
make package-desktop        # builds desktop/bin/Hisar.app (ad-hoc signed)
open desktop/bin/Hisar.app
```

For development with hot reload: `cd desktop && wails3 dev`.

The app keeps its session in `~/Library/Application Support/hisar/desktop.json` (override with `HISAR_DESKTOP_STATE`) and the Secret Key in the macOS Keychain under the service `hisar`.

## Tests

```sh
make test                     # includes desktop/vault unit tests
make test-desktop-frontend    # vue-tsc type-check and Vitest component tests
make test-end-to-end          # includes the desktop backend against a real server
```
