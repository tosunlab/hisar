# Hisar documentation

Hisar is an end-to-end encrypted password, SSH-key and secrets manager for developers. The server stores only ciphertext. Your devices derive the keys from your master password and a Secret Key that never leaves them.

Hisar runs on the Mac, iPhone, Android, Linux, in the browser extension, and from the `hisar` command line. You can use the hosted service at [tryhisar.com](https://tryhisar.com) or run your own server.

## Where to start

- [Download Hisar](https://tryhisar.com/download) for your platform.
- Read the [security model](https://tryhisar.com/security) before you trust it with your secrets.
- The source, releases and issue tracker are on [GitHub](https://github.com/tosunlab/hisar).
